## ✨ Features & Highlights

- 💌 **Interactive Letter / Envelope Intro**:
  - Tap-to-open envelope animation with blooming petal canvas physics.
  - Playful multi-step cute cat dialogue intro card.

- 🎈 **Festive Hero Section**:
  - Floating anti-gravity balloons, confetti, and celebratory bunting decorations.

- 🌀 **3D Spiral Ribbon Gallery**:
  - Artistic spiral photo stream highlighting beautiful moments together.

- 📸 **Draggable Polaroid Collage**:
  - Interactive, physics-based scattered polaroid cards with sweet captions (*Cutie, Baddie, My Love, Beautiful, Dream Girl, Sunshine, Queen, Angel*).

- 🎂 **Interactive 3D Birthday Cake**:
  - Interactive 3D cake model simulation with a cutting knife powered by Google's `@google/model-viewer`.

- 📖 **Embedded Birthday Memory Book**:
  - Integrated digital flipbook loaded with sweet memories and heartfelt letters.

- 🎵 **Background Music Player**:
  - Soothing ambient background music with custom play/pause audio controller.

- 📱 **Fully Responsive & Optimized**:
  - Smooth 60fps animations, optimized assets (WebP/GLB), and responsive layout across desktop and mobile devices.

---

## 🛠️ Built With

- **Core**: HTML5, CSS3, Vanilla JavaScript
- **3D Graphics**: [`@google/model-viewer`](https://modelviewer.dev/) (GLTF/GLB)
- **Typography**: Google Fonts (*Playfair Display*, *Great Vibes*, *Sacramento*, *Poppins*)
- **Hosting**: GitHub Pages

## 🚀 Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/farabiahadtafim/Happy-Birthday-Subha.git
   ```

2. **Navigate to project folder:**
   ```bash
   cd Happy-Birthday-Subha
   ```

3. **Open `index.html`** in your favorite browser (or run via Live Server):
   ```bash
   # Or run start.bat on Windows
   start index.html
   ```
